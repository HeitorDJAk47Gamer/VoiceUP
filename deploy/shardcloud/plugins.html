Plugins são módulos JavaScript executados pelo ServerHost ou Cloud. Eles recebem eventos de chat, respondem como bots, guardam dados persistentes e expõem opções no painel. Participantes não precisam instalar o plugin.

Dados RPGMusic BotXP de Chat
Atenção: um plugin é código de servidor e usa as permissões do processo. Instale somente arquivos confiáveis e teste primeiro em um ServerHost separado.

Como instalar no ServerHost

  1. Baixe o arquivo .js.
  2. Abra o VoiceUP ServerHost e acesse Plugins.
  3. Clique em Abrir pasta de plugins.
  4. Copie o arquivo diretamente para essa pasta.
  5. Clique em Recarregar plugins ou reinicie o servidor.
  6. Habilite o Toggle Switch e abra Editar opções.

Em uma hospedagem Cloud

Inclua o arquivo na pasta plugins do projeto enviado à plataforma e faça um novo deploy. As opções usam PLUGIN_STATE_FILE; dados persistentes exigem que a hospedagem preserve esse arquivo entre reinicializações.

Crie o primeiro plugin

Crie um arquivo boas-vindas.js diretamente na pasta de plugins:

module.exports = {
  id: 'boas-vindas',
  name: 'Boas-vindas',
  version: '1.0.0',
  description: 'Responde ao comando !oi.',

  onTextMessage({ text, room, textChannel, user, api }) {
    if (text.trim().toLowerCase() !== '!oi') return;
    api.systemMessage(room, textChannel, `Olá, ${user.name}!`, {
      name: 'Bot de boas-vindas',
      color: '#56e2cf'
    });
  }
};

Contrato exportado

id, name e onTextMessage são obrigatórios. Também podem ser usados version, description, icon, settings, onEnable, onDisable, getAdminState e onAdminAction.

O contexto de mensagem inclui text, room, textChannel, voiceChannel, user, serverIsCloud, plugin e api.

API disponível

  • api.systemMessage(...) responde no canal de texto.
  • api.settings contém as opções salvas pelo host.
  • api.storage.get/set/delete guarda JSON isolado pelo ID do plugin.
  • api.media.list() lista músicas reconhecidas pelo ServerHost.
  • api.botCommand(...) integra bots de voz compatíveis com o host.
  • api.log(...) escreve no painel de logs.

Opções no painel

O array settings cria controles automaticamente. Tipos disponíveis: text, number, range, boolean, select e image.

settings: [
  { key: 'points', label: 'Pontos', type: 'number',
    default: 5, min: 0, max: 100 },
  { key: 'reply', label: 'Responder no chat', type: 'boolean',
    default: true }
]

Compatibilidade e segurança

  • Erros são isolados e registrados sem interromper os outros plugins.
  • IDs duplicados são ignorados.
  • Clientes antigos recebem respostas como mensagens normais.
  • Não use eval nem execute comandos enviados pelo chat.
  • Não armazene senhas, tokens ou arquivos grandes em api.storage.
  • A API é beta; mantenha a versão do plugin e valide antes de distribuir.
