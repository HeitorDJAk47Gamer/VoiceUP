# Músicas do VoiceUP Server

Coloque aqui arquivos `.mp3`, `.ogg`, `.wav`, `.m4a` ou `.aac`.

No Server Host instalado, a pasta usada é `%APPDATA%\\VoiceUP\\music`. No Cloud, envie a pasta `music` junto com o ZIP e republique.

No chat de uma sala hospedada, use `!music list` e depois `!music play nome-do-arquivo`. Use somente músicas que você pode distribuir para as pessoas da sala.
