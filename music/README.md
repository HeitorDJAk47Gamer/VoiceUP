# Musicas do VoiceUP Server

Coloque aqui arquivos `.mp3`, `.ogg`, `.wav`, `.m4a` ou `.aac`.

No Server Host instalado, a pasta usada e `%APPDATA%\\VoiceUP\\music`.

No chat de uma sala hospedada, use `!music list` e depois `!music play nome-do-arquivo`. O Music Bot entra no mesmo canal de voz e transmite o audio pela chamada, como se fosse o microfone dele. Os participantes nao baixam o arquivo. Use somente musicas que voce pode distribuir para as pessoas da sala.
